# Swagger UI assets

`swagger-ui-bundle.js` and `swagger-ui.css` come from the npm package
`swagger-ui-dist@5.33.1`, published by the Swagger UI project:
https://github.com/swagger-api/swagger-ui.

The accompanying license and third-party notices are retained in this directory.
The HTML page and initializer are maintained by FroggoBank.

To update, download a pinned package with `npm pack swagger-ui-dist@VERSION`,
replace the distribution assets and license notices, and update this version.
Run the router tests and check the documentation in a browser after updating.
